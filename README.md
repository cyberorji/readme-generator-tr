# readme-generator-tr

> Projeler için Türkçe/İngilizce profesyonel README oluşturucu

Bu depo aktif geliştirme altındadır. Amaç; Linux, Windows ve Termux üzerinde kolay kurulabilen, açık kaynak ve topluluk katkısına uygun bir başlangıç sunmaktır.

## Durum

**Başlangıç sürümü / scaffold.** Özellikler aşamalı olarak eklenecektir.

## Kurulum

### Linux

```bash
git clone https://github.com/cyberorji/readme-generator-tr.git
cd readme-generator-tr
```

### Windows (PowerShell)

```powershell
git clone https://github.com/cyberorji/readme-generator-tr.git
Set-Location readme-generator-tr
```

### Termux

```bash
pkg update
pkg install git
git clone https://github.com/cyberorji/readme-generator-tr.git
cd readme-generator-tr
```
